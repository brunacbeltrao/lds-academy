# LDS Academy

Plataforma interna da Liga de Direito Societário e Mercado de Capitais da Faculdade de Direito do Recife (LDS·FDR): ciclos e aulas, biblioteca, competições e tira-dúvidas, com acesso restrito aos membros.

- Stack: Next.js na Vercel e Supabase.
- Documentação: [`docs/`](docs/) (mapa do site, permissões, decisões, identidade visual e arquitetura).
- Regras do projeto: [`CLAUDE.md`](CLAUDE.md).

## Rodar

```bash
npm install
```

```bash
cp .env.example .env.local
```

```bash
npm run dev
```

Este repositório não contém materiais da liga, segredos nem dados de membros.
